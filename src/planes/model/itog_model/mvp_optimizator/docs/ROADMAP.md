# Roadmap — Geoscan Planner

План развития от MVP к production. Разбит на этапы:
- ✅ **MVP** — сделано
- 🟡 **v1.1** — улучшения (что можно добавить в текущий проект)
- 🔵 **v2** — расширения (новая функциональность)
- 🟣 **v3** — production-готовность

---

## ✅ MVP — сделано

- Генерация полос: trapezoid + triangulation
- Merge тонких кусков декомпозиции
- Учёт препятствий (KML)
- DEM из KML (плоская земля + точки высот)
- Векторный ветер (направление + скорость)
- Зарядка АКБ (время между вылетами)
- Кластеризация K-Means + назначение Венгерским
- Маршрутизация OR-Tools (T, E, m)
- Внешний цикл по углам θ
- Валидатор: покрытие, T, E, m, рельеф, препятствия
- Экспорт KML + JSON
- Folium-визуализация
- Сравнение методов (plot + карты + CSV)
- 10 unit/integration тестов

## 🔵 v2 — расширения

### Поддержка БВС
- [ ] **Geoscan 201 (fixed-wing)**:
  - новая физика: `fixedwing.py` (уже есть каркас)
  - катапульта: `T_catapult + h/v_climb`
  - парашют: `h/v_descend + T_parachute`
  - вираж: `R = v² / (g·tan φ)`
  - скорость сваливания: `V_ground ≥ v_stall − |w|`
  - формула мощности через аэродинамику

### Площадки и логистика
- [ ] **Несколько ВПП** — multi-depot VRP
- [ ] **Назначение ВПП** — часть оптимизации, не вход
- [ ] **Расписание зарядок** — если зарядных станций меньше, чем бортов
- [ ] **Дозаправка** — несколько АКБ на борт

### Оборудование
- [ ] **2 камеры на 201** — левый + правый слот
- [ ] **Совместимость камеры и типа съёмки** — visible / multispectral / thermal
- [ ] **Офсеты камер** — для постобработки (уже в data.json)
- [ ] **Мультиспектральная съёмка** (Pollux) — 5 каналов

### Оптимизация
- [ ] **Направление полос — оптимизируемое**: перебор 12 углов или адаптивно
- [ ] **Boustrophedon-декомпозиция** — третий метод:
  - sweep-line с критическими точками
  - минимум разворотов
  - стандарт для сельхоз-АФС
- [ ] **Pareto-фронт** — min_time vs min_flight_hours одновременно
- [ ] **Коллизии между бортами**:
  - эшелоны высоты (разные высоты → коллизий нет)
  - 4D-проверка (траектории во времени)

### Точность модели
- [ ] **Угол попадания камеры (off-nadir)** — наклон 10–20°
- [ ] **Продольное и поперечное перекрытие отдельно**
- [ ] **DEM в растре (GeoTIFF)** — вместо точек KML
- [ ] **Билинейная интерполяция высот** — вместо «ближайшая точка»
- [ ] **Ветер по высотам** — если разные эшелоны

## Что НЕ делаем (сознательно)

- **Тензорный ветер** — CFD-уровень, не нужен для АФС
- **Реальное время** — перепланирование в полёте, отдельная тема
- **Машинное обучение** — оптимизация классическими методами
- **Мобильное приложение** — не в скоупе
- **3D-визуализация рельефа** — для отчёта хватит 2D + карты

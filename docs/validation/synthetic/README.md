# Синтетические KML для ручной проверки

Эти файлы — фикстуры для ручной проверки. Они не утверждают, что кривая пара уже была отправлена через форму.

Значения полей взяты из общего профиля и случаев 1, 2, 3 и 17, а для кривых контуров — из сценария кривых полигонов. Новых значений здесь нет.

Если случай не меняет поле, оставить общий профиль.

Запятая в числе равна точке: `0,6` вводить как `0.6`.

## survey-one.kml

Один прямой прямоугольник. Имя полигона `survey`. Кольцо начинается с `37.600,55.750`. Прямоугольник рельефа этого файла: `west=37.60000000`, `south=55.75000000`, `east=37.60800000`, `north=55.75400000`.

Случаи 1 и 3. Оставить все поля общего профиля. В случае 1 зоны ограничений не загружать.

Случай 17 меняет тип съёмки на «Мультиспектральная». Камера остаётся Geoscan PF1B (RGB) из общего профиля. Остальные поля общего профиля не меняются. Зоны ограничений не загружать.

## survey-two.kml

Два прямых полигона, `North` и `South`. Первая точка North — `[37.601, 55.748]`, South — `[37.601, 55.74]`.

Случай 2. Оставить все поля общего профиля. Зоны ограничений не загружать. Поля относительно общего профиля не меняются.

## constraints-alt.kml

Прямое ограничение. Имя `Сектор А`, тип `врем_ограничение`. Текст высот `от 800 м AMSL до FL90` копируется как текст и в метры не переводится.

Случай 3, вместе с `survey-one.kml`. Оставить все поля общего профиля. Поля формы относительно общего профиля не меняются.

## survey-crooked.kml

Два кривых кольца съёмки. Оба контура простые, без самопересечений, и оба не прямоугольники. «Северный излом» с вмятиной внутрь. «Южный излом» — отдельный пятиугольник южнее.

Пара к `constraints-crooked.kml`. Площадка лежит в промежутке между двумя контурами, не внутри них.

Из общего профиля оставить:

- число аэродромов: 1
- аэродром 1: долгота 37.604, широта 55.748
- БВС 1: Геоскан Gemini, Geoscan PF1B (RGB), аэродром 1, количество 1
- тип съёмки: RGB
- скорость ветра, м/с: 1
- направление ветра, откуда, °: 90
- критерий: Минимальное время выполнения
- Seed: 7

Меняются поля сценария кривых полигонов:

| Поле | Значение |
|---|---|
| Идентификатор сценария | `crooked-polygons` |
| GSD, см/пикс | 3 |
| Перекрытие вдоль | 0.7 |
| Перекрытие поперёк | 0.6 |
| Направление полос, ° | 20 |
| Лимит расчёта, с | 110 |

## constraints-crooked.kml

Кривое ограничение внутри северного кольца: один кривой пятиугольник «Излом запрета». Фраза высот `от 120 м AGL до 400 м AGL` копируется текстом и в метры не переводится.

Загружать вместе с `survey-crooked.kml`. Поля формы те же, что у кривого сценария выше: из общего профиля остаются аэродром, борт, тип RGB, ветер, критерий и seed; меняются идентификатор `crooked-polygons`, GSD `3`, перекрытие вдоль `0.7`, перекрытие поперёк `0.6`, направление полос `20`, лимит `110` с.

Эти два кривых файла — фикстуры для ручной проверки. Наличие файлов не означает, что эта пара уже отправлялась через форму.

## Что читать агенту

1. [`REQUIREMENTS.md`](REQUIREMENTS.md) — обязательные требования, рекомендации, сдача и оценка со стабильными ID.
2. [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md) — что заказчик не определил и что нельзя молча додумывать.
3. [`TRACEABILITY.md`](TRACEABILITY.md) — связь требований с ветками, компонентами и доказательствами.
4. Затем — относящиеся к задаче контракты, ADR, task brief и status-файл.

## Классы утверждений

| Метка | Смысл |
|---|---|
| `TZ-MUST` | Прямое обязательное требование исходного ТЗ |
| `TZ-SHOULD` | Рекомендация исходного ТЗ, а не обязательный стек |
| `TEAM-DECISION` | Решение команды о способе реализации |
| `TEAM-ASSUMPTION` | Временное допущение, требующее явной фиксации и проверки |
| `OPEN` | Не определено исходным ТЗ |

Агенту запрещено выдавать `TEAM-DECISION`, `TEAM-ASSUMPTION` или `OPEN` за требование заказчика.

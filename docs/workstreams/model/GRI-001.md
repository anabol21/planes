# GRI-001 — simplified optimizer prototype

- Owner: Grisha

- Allowed paths: `src/planes/model/**`, `tests/model/**`, `docs/status/model.md`
- Target checkpoint: 2026-09-22

## Fixed simplified scope

- `N ≥ 1` identical Geoscan Gemini UAVs;
- identical Sony UMC-R10C payload;
- one common takeoff/landing point;
- rectangular GeoJSON survey area on a flat plane;
- one GSD and derived flight height;
- constant wind vector and cruise speed;
- mass, maximum 40-minute flight time, and 144.7 Wh battery constraint;
- one sortie per UAV;
- objective selected as `min_time` or `min_flight_hours`.

Treat equipment numbers as profile data with sources/assumptions, not hidden constants.

## Deliverable

1. Deterministic input fixture and documented assumptions.
2. Strip generation and route representation.
3. Feasibility calculation for time, energy, and wind.
4. Small-instance exact/exhaustive or MILP baseline.
5. Approximate solution (the proposed K-Means + GA + 2-opt stack may be simplified if justified).
6. Comparison table: objectives, feasibility, runtime, seed, and exact gap where available.
7. Library/CLI entry point returning a versionable result; no notebook-only implementation.

## Acceptance

- Both objectives run on the same fixture and can produce different plans.
- Every strip is assigned exactly once; each used UAV satisfies time and energy limits.
- Same input and seed reproduce the result.
- At least one small case is compared with an exact baseline.
- Heuristic output is not presented as guaranteed optimal.
- Tests cover feasible, infeasible, and objective-switch cases.

## Not in this task

Heterogeneous UAVs/payloads, multiple launch sites, terrain, no-fly zones, repeat sorties, collision avoidance, realtime weather, dynamic replanning, and full M-CATALOG enumeration.

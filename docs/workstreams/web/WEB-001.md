## Goal

Create a minimal browser client for the backend asynchronous job lifecycle.

## Scope

- React + TypeScript + Vite single-page application.
- Scenario JSON editor.
- Optimization JSON editor.
- Seed input.
- Submit a job to the backend.
- Display the returned job ID.
- Poll job status.
- Fetch the terminal result.
- Display feasible, infeasible, `timed_out`, and failed states.
- Show request, network, and backend errors visibly.
- Perform no browser-side optimization or domain calculations.

## Acceptance criteria

- Dependencies are local to `apps/web`.
- No root package configuration changes are made.
- The browser client uses `/api`.
- Vite proxies `/api` to `http://127.0.0.1:8000`.
- `POST /jobs` submission works through the proxy.
- Queued, running, and terminal lifecycle states are visible.
- Polling terminates correctly at a terminal state.
- The terminal result is fetched exactly once.
- Polling is cancelled on resubmit and component unmount.
- Malformed editor JSON is reported visibly.
- Feasible, infeasible, `timed_out`, and failed outcomes are visually distinct.
- Deterministic frontend tests pass.
- The production build passes.
- A manual browser smoke run against the RUS-001 backend is documented.

## Boundary

The web client consumes documented backend HTTP payloads and renders authoritative backend state. It does not import Python implementation internals or calculate routes, feasibility, optimization, or mission plans.

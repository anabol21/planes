# DOC-PROJECT-001 — документация действующего контура

**Роль:** integration. **Контракт:** `v0`. **Цель:** общепроектная документация по фактическому коду и проверкам без изменений production и test code. **Целевая ветка:** `main` по прямому указанию пользователя; работа ведётся в отдельной docs-ветке от terrain-enabled tip.

**Область:** `README.md`, `docs/**`, при необходимости Markdown в `infra/`. **REQ:** `REQ-DOC-001`–`006` (документирование реализации), с трассировкой остальных `REQ-*` без объявления их автоматически закрытыми. **Открытые вопросы:** `OPEN-001`–`021` сохраняют статус из [реестра](../../spec/OPEN_QUESTIONS.md); особенно `OPEN-004`, `OPEN-005`, `OPEN-007`, `OPEN-008`, `OPEN-011`–`013`, `OPEN-020`.

**Приёмка:** один технический entry point, актуальные README/map/one-pager/runbook, проверенные относительные ссылки, `python scripts/validate_workspace.py`, `git diff --check`, только документационный diff. Исторические workstreams/status/checkpoints не переписываются. Доказанный terrain CI не равен доказательству deployment.
